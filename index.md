# My Portfolio

I have linked some of my more interesting previous projects. Most, if not all, have been shelved. I tend to notice better ways to do things as I get further along a project, which all but inevitably results in me wanting to start afresh.  

I am currently looking at [NVIDIA's DesignWorks Samples](https://github.com/nvpro-samples). While working on my first project involving Vulkan some new conventions were only beginning to cement themselves as the de-facto. NVIDIA  has kindly provided a pretty comprehensive resource containing what moden Vulkan usage should look like. Within a year I'm hoping to get my own render/game engine refreshed understanding of [dynamic, bindless rendering](https://docs.vulkan.org/samples/latest/samples/extensions/dynamic_rendering/README.html).

I've recently purchased an ex-workstation PC that I've refitted to be a server. My network is behind CGNAT, though I've set up both Tailscale and a VPS on an external network to get around that limitation. I host some services, such as Jellyfin, through I'm now experimenting with hosting my own pages. Nothing major is up yet, as I'm very conscious that I might knock something importation offline as I work through configuring my server.

As a Programming for games student, I have participated in various game-jams. These occur across a very limited time frame, so I prefer to use the game engine Godot. It lends itself well to rapid prototyping. You can find my submissions [here](https://nonote.itch.io/).

I hope that you enjoy what you see. If you don't, check in later and I'll likely have added something new.
